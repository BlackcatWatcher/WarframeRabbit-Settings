Warframe Rabbit 个性化编辑器使用教程

网页版与本地便携版均采用 4 步向导：填包信息与选样式 → 传角色和背景 → 调尺寸透明度 → 调配色。下方整理了详细操作步骤与常见避坑提醒。

一、开始使用（网页版与便携版）

  1. 帮助中心网页版：打开网页即可直接编辑、实时预览并导出 .wrpersonality，无需安装软件，适合绝大多数群定制。
  2. 本地便携版：解压便携包后双击 WarframeRabbit-PersonalityEditor.exe（或运行启动脚本），浏览器会自动打开本地编辑页；额外支持自定义 HTML 模板编辑、本地自定义字体目录与真实 Chrome 截图渲染。
  3. 新建或继续修改：页面默认自动载入一份“新建默认方案”；如果想在旧方案上继续微调，点击右上角“打开个性化包”载入已有 .wrpersonality 文件即可。

提醒：所有改动在点击“导出个性化包”前都只保存在当前浏览器页面中，刷新或关闭页面会丢失未导出内容，调整满意后请及时导出备份。

二、第 1 步：填写包信息

本步只需设置三项必要信息；新建方案使用默认基础语言、布局和备注，打开已有包时保留包内值。导入后按包内设置生效：

  • 目标群号 / 群 UID（必填）：QQ 群直接填写 5–20 位纯数字群号（首位不能为 0，系统自动补 1g）；KOOK、黑盒语音、QQ 官方等其他平台必须填写完整群 UID（例如 3g123456），在群内发送 .状态 即可查看。请仔细核对群号，填错会导致无法正确绑定目标群。
  • 字体：选择目标显示的字体名称。导出包只记录字体名、不打包字体文件；网页版仅按需下载所选字体的预览子集，若预览旁提示个别生僻字使用默认字体补字属于正常现象，最终效果取决于机器人所在环境是否安装完整字体。
  • HTML 样式：内置 100 套样式，占用一整行展示：
    • 点击两侧左右箭头，或直接按键盘 ← / → 方向键逐套切换；
    • 拖动下方醒目滚动条，可快速翻动并实时定位到任意样式；
    • 点击最下方的向下箭头展开全部样式列表，支持按名称或编号搜索，点击目标样式即可自动收起并选中。

提示：切换内置样式时，尚未手动改动过的配色与透明度会自动跟随新样式更新，你手动调整过的参数则会保留。

三、第 2 步：上传角色和背景图

点击上传区域或直接把图片拖拽进卡片，即可分别替换角色图（右下角立绘/图案）和背景图；不上传则沿用当前包内默认图片，随时可点“恢复原图”撤销替换。

准备图片的重要注意事项：

  • 角色图务必先抠图透明：角色图叠加在卡片右下角，一定要先去除背景并保存为透明底 PNG；如果直接上传带白底或实色背景的图片，画面右下角会出现一大块遮挡正文的方块。
  • 裁剪掉角色图多余留白：四周留白过宽会让角色显得偏小、位置难对准，建议抠图后紧贴角色主体裁剪，朝向左侧或居中的立绘通常更贴合右下角布局。
  • 背景图注意清晰度与构图：优先选择对比度温和、画面不杂乱的高清图，避免高饱和碎纹干扰正文阅读。
  • 格式与体积限制：只接受标准 PNG 或 JPEG（不支持 WebP、GIF，也不能直接把其他格式手动改后缀为 .png，校验会拒绝）。单张背景最大 10 MiB、角色最大 8 MiB，单边不超过 8192 px，总像素不超过 16,777,216，整个压缩包不超过 20 MiB。

四、第 3 步：尺寸与透明度

本步每项参数都提供“滑块 + 数值输入框”双控制：滑块仅作为常用参考范围，如果希望微调到更极限的数值，可直接在输入框填写后端完整允许范围内的整数：

  • 字号：滑块参考 60–150（对应 15px–37.5px），输入框支持 30–150；实际字号按数值的 1/4 计算，最低 14px，默认 95。字号过大时请切换右侧“市场”“紫卡分析”等长表预览确认不会挤压换行。
  • 相对宽度：滑块参考 700–1000，输入框支持 600–1200，以 800 为基准。例如填 1000 表示所有功能整体加宽 200（默认 1200 的页面变为 1400）。
  • 角色尺寸与偏移：尺寸滑块 100–280（输入 80–360）；水平/垂直偏移滑块 -200–200（输入 -400–400），正数分别向右、向下移动，负数向左、向上移动。
  • 背景图不透明度（0–100）：0 为隐藏背景图，调高让背景图更清晰。如果背景较花导致文字费眼，建议控制在 20–55 并配合内容底色或毛玻璃使用。
  • 内容底色不透明度 / 毛玻璃强度（0–100）：与“启用主内容层毛玻璃”开关互斥——关闭毛玻璃时控制正文区底色不透明度；开启毛玻璃后改为控制玻璃模糊强度，正文与角色保持清晰。
  • 角色不透明度：滑块参考 0–100，输入框支持 0–200。100 为正常不透明；当角色图案与正文文字重叠时，系统会自动把角色透明度减半避免挡字，若觉得太淡，可在输入框填到 101–200 抵消自动减半效果。

五、第 4 步：配色与多场景预览

配色分为“框架与主题色”（背景、外框、边框文字、主题色）与“正文与状态文字色”（基础、数值、通知、成功、信息、警告、备注），支持取色器点击或直接粘贴 6 位 HEX 色值（如 #159D2B）。

  • 想重置为当前 HTML 样式的官方推荐配色和透明度，点击右上角“恢复主题建议值”。
  • 导出前务必多切几个右侧预览场景：建议至少检查“仲裁”（短卡片）、“市场 / 紫卡分析”（多列数值与状态色）和“全部组件”（覆盖所有语义颜色），确认深浅背景下的所有文字对比度清晰、没有被角色挡住重要信息。

参数停止改动约 180 毫秒后右侧预览会自动刷新，也可随时点击预览按钮手动立即刷新。

六、进阶：自定义 HTML 与 i18n 文案（可选）

自定义 HTML 主题（便携版）：点击页面顶部“i18n 文案”右侧的“自定义 HTML 主题”标签页并启用，即可载入完整组件标准模板、上传组件装饰素材并进行代码编辑；需要恢复内置样式时可随时点击“切回内置样式”或在样式条直接点选任意内置样式。不要加入 JavaScript / <script>、表单、<iframe>、远程 URL、本机绝对路径或隐藏 #rabbit-card 的代码；改坏时可点“恢复安全基础模板”。网页版不支持新建或修改自定义 HTML，但导入已有自定义包时会原样保留其模板内容。

i18n 文案：切换到顶部“i18n 文案（可选）”标签可修改页脚提示 FooterText（最多 60 字且不能换行）及各功能开头语；正文和表头由功能自身维护。批量编辑时请只改文字值，不要修改字段名或破坏 JSON 格式。

七、导出个性化包与交付

  1. 确认第 1 步已填入正确的目标群号 / 群 UID，且右侧预览清晰无异常。
  2. 点击第 4 步底部的“完成并导出个性化包”或页面右上角“导出个性化包”。
  3. 浏览器会下载 群号.wrpersonality 文件（已完整打包配置、i18n 文案、背景图和角色图，无需再单独发送原图）。
  4. 把该文件发给负责导入的机器人管理员；管理员导入后会自动绑定目标群并发送启用命令。

八、常见问题

上传角色图后右下角有一块白色/实色底框：
角色图没有做透明背景处理。请先用抠图工具去掉背景，导出为真正的透明底 PNG 后再回到第 2 步重新上传。
上传图片提示“格式与扩展名不一致”或无效：
不能直接重命名 WebP、GIF 等图片后缀。请用画图、Photoshop 或格式转换工具重新导出为标准 PNG 或 JPEG。
角色图挡住正文，或者角色看起来很淡：
挡字时请在第 3 步调小“角色尺寸”并微调水平/垂直偏移；如果角色与正文重叠触发了防遮挡自动变淡，可将“角色不透明度”输入框调高到 120–200。
背景图加上去以后字看不清：
在第 3 步降低“背景图不透明度”，并提高“内容底色不透明度”或开启“毛玻璃”；同时在第 4 步调整背景色与文字色对比度。
网页版预览提示部分文字使用默认字体补字，或便携版缺少想要的字体：
网页版只下载精简预览子集，出现补字提示属正常现象，导出包仍会保存所选字体名；便携版可将 .ttf/.otf/.ttc/.woff/.woff2 字体放入 font 或 WRData\font 目录后重启编辑器。
导出后还想继续修改：
点击右上角“打开个性化包”重新载入刚导出的 .wrpersonality 即可继续编辑。
