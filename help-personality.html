Warframe Rabbit 个性化编辑器使用教程

在网页版调整外观、预览效果和导出个性化包。下方教程介绍独立编辑器的使用方法。

打开网页版编辑器
目录 打开编辑器 新建或打开个性化 可以修改什么 自定义 HTML 修改 i18n 文案 导出个性化包 常见问题

一、打开编辑器

  1. 双击“WarframeRabbit-PersonalityEditor.exe”。
  2. 程序会自动打开浏览器页面；所有编辑和预览都在本机完成。
  3. 使用结束后，关闭程序窗口和浏览器页面即可。

二、新建或打开个性化

新建：
点击右上角“新建默认方案”，从默认样式开始修改。

继续修改已有文件：
点击“打开个性化包”，选择扩展名为 .wrpersonality 的文件。

包信息需要填写：

  • 目标 QQ 群号：填写纯数字群号，其他平台需要完整UID，输入 .状态 可见。
  • 个性化备注：用于说明这套样式，例如“粉色简约版”“深色科幻版”。

三、可以修改什么

在“外观与素材”页面可以修改：

  • 内置 HTML 样式和长短图布局。
  • 字体、字号和图片最大宽度。
  • 背景图、右侧角色图案及其大小、偏移和透明度。
  • 背景、边框、主题、正文、数值、提示、警告等颜色。
  • 背景和内容区域的透明度。
  • 毛玻璃效果。
  • 自定义 HTML 模板。

替换图片时支持 PNG 和 JPEG。建议背景图尺寸足够大，右侧角色图使用透明背景 PNG。

页面右侧提供五套测试内容：短状态、数据表格、五列长文本、长列表和全英文。修改后点击“构建并生成预览”，应当至少检查短图、长图和全英文三种情况。

四、自定义 HTML

在“HTML 样式”中选择“自定义 HTML”，编辑器会自动填入一份完整安全模板。

可以修改模板中的 HTML 和 CSS，但不要加入：

  • JavaScript 或 script 标签。
  • 表单、iframe、外部网页和远程资源。
  • 本机绝对路径。
  • 会遮挡或移除 #rabbit-card 主卡片的代码。

如果模板改坏，可以点击“恢复安全基础模板”。恢复操作会覆盖当前自定义 HTML，请先保存需要保留的内容。

五、修改 i18n 文案

  1. 切换到“i18n 文案”页面。
  2. 默认提供国际服文案；需要国服时点击“+ 国服”。
  3. 需要其他语言时填写 locale，例如 ja 或 zh-Hant，再点击“添加其他语言”。
  4. “分类字段”适合日常修改；每个分类可以展开后逐项编辑。
  5. “格式化 JSON”用于整体检查和复制，不熟悉 JSON 时不要直接大批量改结构。
  6. “导出 raw i18n”可以单独备份当前文案；“导入 raw i18n”可以恢复或迁移文案。

注意：不要修改字段名称，只修改字段对应的文字。删除逗号、引号或括号可能导致 JSON 无法导入。

六、导出个性化包

  1. 先生成预览并确认没有明显错位、文字溢出或颜色看不清。
  2. 点击右上角“导出个性化包”。
  3. 浏览器会下载“群号.wrpersonality”。
  4. 将这个文件交给负责导入的管理员即可。

.wrpersonality 已经包含配置、i18n 文案、背景图和角色图，不需要再单独发送这些素材。

七、常见问题

字体下拉框没有想要的字体：
把字体文件放入便携包的 WRData\font 后重新启动编辑器。支持 ttf、otf、ttc、woff、woff2。
预览提示模板或图片无效：
先恢复安全基础模板；图片则重新保存为标准 PNG 或 JPEG 后再上传。
右侧图案挡住文字：
降低角色尺寸或透明度，调整水平、垂直偏移，并检查长列表预览。
导出按钮不可用：
等待默认方案载入完成，或重新打开一个有效的 .wrpersonality 文件。
导出后还想继续修改：
重新打开刚导出的 .wrpersonality 文件即可继续编辑。
